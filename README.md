# УМНИК TV (UNEK TV)

Первая веб-версия интерфейса Smart TV. Это не прошивка телевизора и не Android TV: проект запускается как веб-приложение в браузере, а более полная версия может работать на внешнем устройстве через HDMI.

## Что уже есть в Web MVP

- Экран приветствия и домашний экран в тёмном Liquid Glass стиле.
- Разделы: главная, Live TV, фильмы, мультфильмы, приложения, игры, избранное, история и настройки.
- Навигация с клавиатуры/частью TV-пультов: стрелки, Enter, Backspace/Escape.
- Сохранение языка, избранного, истории и импортированного списка каналов в localStorage (если браузер это поддерживает).
- Импорт M3U с проверкой HTTP(S)-адресов; список каналов сохраняется локально.
- Воспроизведение прямых потоков через встроенный HTML5-плеер, если формат поддерживается браузером.
- Импорт XMLTV: программа передач сохраняется локально и показывает предстоящие передачи на ближайшие 12 часов.
- Ссылки на официальные сайты YouTube, Netflix, Spotify, Apple TV и Twitch.
- VPN-раздел честно показывает, что VPN не подключён: обычная веб-страница не может включить системный VPN телевизора.
- HDMI-раздел подсказывает использовать физическую кнопку SOURCE/Источник на пульте: веб-страница не может переключить вход телевизора.
- Переводы интерфейса RU / ES / EN / PL.

## Запуск

1. Открой GitHub Pages для репозитория (Settings → Pages).
2. Выбери публикацию из ветки `main`, папка `/ (root)`.
3. После публикации открой выданный GitHub Pages адрес в браузере.
4. Для проверки на компьютере можно открыть `index.html` напрямую или запустить локальный статический сервер.

## Важно для Samsung 2013

Samsung Smart TV 2013 года относится к Samsung Legacy Platform (Orsay), а не к Tizen. Совместимость зависит от точной модели, региона, прошивки и возможностей встроенного браузера. Поэтому проект написан без сборщика, модулей JavaScript и обязательных современных API, но реальная работа должна быть проверена на самом телевизоре.

Найти код модели можно в меню телевизора: **Поддержка → Об этом телевизоре** (названия пунктов могут отличаться).

Веб-приложение не может:
- заменить прошивку Samsung или превратить Orsay в Android TV;
- установить системный VPN или достоверно проверить VPN роутера;
- переключать HDMI-входы;
- гарантировать запуск современных версий Netflix / Apple TV / YouTube;
- обойти DRM, платные подписки, региональные ограничения или авторизацию.

Для полноценного современного интерфейса и приложений потребуется внешнее совместимое HDMI-устройство. В таком случае Web-версия может служить оболочкой, а возможности VPN, DRM и воспроизведения определяются самим устройством и официальными приложениями.

## Безопасность и источники

Используй только каналы, плейлисты и видео, на распространение которых есть разрешение. Не публикуй личные плейлисты, токены или пароли в открытом репозитории.

- Проверить импорт M3U, XMLTV и воспроизведение потоков на целевом телевизоре; поддержка кодеков и HLS зависит от браузера.

- Добавить сборку для внешнего TV-устройства и автоматические тесты.
- Проверить совместимость сервисов на целевом устройстве; не считать ссылки на веб-сайты гарантией их работы на телевизоре.

## Технологии

Vanilla HTML, CSS и JavaScript в ES5-совместимом стиле, без npm-зависимостей и внешних библиотек.
